# AI Doctor Project

## Overview

AI Doctor Project is an intelligent healthcare assistance system developed using Python and Flask. The main purpose of this project is to help users get basic medical guidance by analyzing symptoms and providing AI-generated health suggestions. The application is designed with a simple and user-friendly interface so that users can easily interact with the system.

This project combines artificial intelligence concepts, chatbot functionality, OCR technology, and database management to create a smart medical support platform. It is mainly developed for learning purposes and demonstrates how AI can be integrated into healthcare applications.

---

# Features

* AI-based symptom analysis
* Smart healthcare chatbot
* User authentication system

# Installation and Setup

## Step 1: Clone the Repository

```bash
git clone https://github.com/chandrashekar799/AI_DOCTOR_PROJECT.git
```

## Step 2: Navigate to Project Folder

```bash
cd AI_DOCTOR_PROJECT
```

## Step 3: Create Virtual Environment

```bash
python -m venv venv
```

## Step 4: Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

## Step 5: Install Dependencies

```bash
pip install -r requirements.txt
```

## Step 6: Run the Application

```bash
python app.py
```

# Working of the Project

1. Users enter symptoms or health-related queries.
2. The AI engine processes the input data.
3. The chatbot analyzes symptoms and generates suggestions.
4. OCR technology extracts text from uploaded medical reports if needed.
5. The system displays possible medical guidance to the user.
